# 고스란 (goseuran)

> 떠오른 순간을, 고스란히.

떠오른 순간을 한 줄씩 남기면 저장한 시각이 자동으로 찍히고, 하루를 마칠 때 AI가 그날의 기록을 짧은 일기체 에세이와 분류로 정리해 주는 웹 서비스입니다.

- 배포 주소: https://goseuran.vercel.app
- 서비스 기획서: [docs/service-plan.md](docs/service-plan.md)
- AI 코딩 도구 사용 기록: [docs/ai-usage-log.md](docs/ai-usage-log.md)
- 증빙 스크린샷: [docs/evidence](docs/evidence)

## 평가용 접근 코드

AI 호출은 접근 코드로 보호합니다. 평가 기간에는 아래 임시 코드를 사용합니다.

| 항목 | 값 |
|---|---|
| 평가용 임시 코드 | `test00*` |

- `하루 정리하기`를 누르면 코드 입력칸이 나타납니다. 위 코드를 입력하면 AI 결과가 표시됩니다.
- 이 코드는 평가 기간용이며, 평가가 끝나면 교체합니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 한 줄 기록 | 입력 후 Enter 또는 저장 버튼. 저장 시각이 자동으로 기록됨. 한 번에 300자, 하루 30개까지 |
| 오늘의 타임라인 | 오늘 남긴 기록을 시각 순으로 표시. 기록은 수정할 수 없고 삭제만 가능(삭제 전 확인) |
| 지난 기록 | 연도와 월을 골라 날짜별로 다시 보기. 기록이 없는 달은 선택할 수 없음 |
| 하루 정리하기(AI) | 오늘의 기록을 바탕으로 짧은 일기체 에세이, 기록별 분류(6가지), 정돈 문장을 생성 |
| 예시 기록 | 처음 써 보는 사람과 시연을 위한 샘플 기록 넣기와 지우기 |
| 반응형 | 휴대폰, 태블릿, 데스크톱 화면에 맞춰 배치 |
| 다크 모드(보너스) | 기기 설정을 따르고, 오른쪽 위 버튼으로 직접 전환. 고른 화면은 브라우저에 기억 |

### AI 정리의 원칙

- 기록에 적힌 사실만 사용합니다. 없는 사람, 장소, 감정, 이유를 만들지 않습니다.
- 낱말을 바꾸지 않고, 이웃한 기록을 "~고", "~며"로 이어 압축합니다.
- 기록 사이에 없는 대조나 인과(지만, 그래서 등)를 만들지 않습니다.
- 저장 시각으로 시간대를 추측하지 않습니다. 기록 안에 적힌 시간 표현만 씁니다.
- 감정이 적힌 기록이 있으면 그 감정만 모아 총평 한 문장을 씁니다.
- 기록의 원문은 타임라인에 그대로 남고, AI 결과는 "AI가 정리한 결과"로 구분해 표시합니다.

## 기술 스택

| 구분 | 사용 기술 |
|---|---|
| 프론트엔드 | HTML, CSS, JavaScript(프레임워크 없음) |
| 백엔드 | Vercel Serverless Functions(Python, `api/review.py`) |
| AI | Anthropic 방식 API, 모델 `claude-haiku-4`(교육 과정 제공 API 사용) |
| 저장 | 브라우저 localStorage |
| 배포 | Vercel(GitHub 연동, `main` 브랜치 자동 배포) |

## 동작 흐름

1. 브라우저가 기록을 localStorage에 저장합니다.
2. `하루 정리하기`를 누르면 오늘 기록(id와 글)을 `fetch('/api/review')`로 보냅니다.
3. 서버 함수가 접근 코드와 입력을 검사한 뒤 AI API를 호출합니다.
4. 서버가 AI 응답(JSON)을 검증하고 분류 범위를 확인해 화면에 돌려줍니다.
5. 실패하면 원인에 맞는 안내 문구를 화면에 표시합니다.

## 환경 변수 설정

API 키와 접근 코드는 코드와 문서에 넣지 않고 Vercel의 환경 변수로만 관리합니다. 평가용 임시 코드만 평가 기간에 한해 이 문서에 공개합니다.

Vercel 프로젝트 → `Settings` → `Environment Variables`에서 아래 값을 추가합니다.

| 이름 | 예시 값 | 종류 | 설명 |
|---|---|---|---|
| `AI_BASE_URL` | `https://copa.codyssey.kr` | Config | AI API 기본 주소 |
| `AI_PROVIDER` | `anthropic` | Config | `anthropic` 또는 `openai` |
| `AI_MODEL` | `claude-haiku-4` | Config | 사용할 모델 |
| `ANTHROPIC_API_KEY` | (비공개) | Secret | `AI_PROVIDER`가 `anthropic`일 때 필요 |
| `OPENAI_API_KEY` | (비공개) | Secret | `AI_PROVIDER`가 `openai`일 때 필요 |
| `ACCESS_CODE` | (평가 기간에는 위 임시 코드) | Secret | AI 호출을 보호하는 접근 코드. 비워 두면 접근 코드 없이 동작 |

환경 변수를 바꾼 뒤에는 새 배포(`Redeploy`)가 있어야 적용됩니다.

설정 상태는 `https://goseuran.vercel.app/api/review`(GET)에서 확인할 수 있습니다. 키와 코드의 값은 표시하지 않고 설정 여부만 표시합니다.

## 실행과 배포

### 배포(사용한 방식)

1. GitHub 저장소를 Vercel에 연결합니다(`Add New` → `Project` → 저장소 `Import`, Preset은 `Other`).
2. 위 환경 변수를 입력합니다.
3. `main` 브랜치에 커밋하면 자동으로 배포됩니다.

### 로컬에서 보기

- `index.html`을 브라우저로 열면 기록 저장, 타임라인, 지난 기록, 다크 모드는 동작합니다.
- `하루 정리하기`는 서버 함수가 필요해서 배포된 주소에서 동작합니다. 로컬 파일로 열면 "서버에 연결하지 못했어요" 안내가 표시됩니다.
- 로컬에서 서버 함수까지 실행하려면 Vercel CLI의 `vercel dev`를 사용할 수 있습니다. 이 프로젝트에서는 시험하지 않았습니다.

## 접근 코드의 동작

- 코드 없이 `하루 정리하기`를 누르면 코드 입력칸이 나타나고, 서버는 AI를 호출하지 않습니다.
- 코드가 틀리면 1초 뒤 거절하며, 이때도 AI를 호출하지 않습니다(토큰 사용량이 늘지 않음을 확인).
- 맞는 코드는 그 탭에서만 기억하고, 새로 고치면 지워집니다.

## 보안: API 키 관리와 유출 대응

- 키는 Vercel 환경 변수(Secret)에만 저장하고, 코드, README, 스크린샷, 커밋에 넣지 않았습니다.
- `.gitignore`에 `.env` 파일을 포함해 실수로 올라가지 않게 했습니다.

키 유출이 의심되면 아래 순서로 대응합니다.

1. 키를 발급한 곳에서 기존 키를 폐기하고 새 키를 발급합니다.
2. Vercel 환경 변수를 새 키로 바꾸고 `Redeploy`합니다.
3. 키가 커밋에 들어갔다면 저장소 이력에서 해당 내용을 제거하고(예: `git filter-repo`) 강제 푸시합니다. 이미 노출된 키는 이력을 지워도 다시 쓰지 않습니다.
4. 사용량 화면에서 이상 사용이 있었는지 확인합니다.

| 상황 | 화면 안내 |
|---|---|
| 빈 입력 저장 | 내용을 입력해 주세요. |
| 300자 초과 입력 | 한 번에 300자까지 저장할 수 있어요. 지금은 N자예요. 나눠서 적어 주세요. |
| 하루 30개 초과 | 오늘은 30개를 모두 저장했어요. 내일 이어서 남겨 주세요. |

| 접근 코드 틀림 | 접근 코드가 맞지 않아요. 다시 확인해 주세요. |
| AI 응답 지연(서버 25초, 화면 30초) | 응답이 늦어지고 있어요. 잠시 후 다시 시도해 주세요. |
| AI 서비스 오류 | AI 서비스에서 오류가 났어요. 잠시 후 다시 시도해 주세요. |
| AI 결과 형식 오류 | AI 결과를 정리하지 못했어요. 다시 시도해 주세요. |
| 인터넷 연결 실패 | 서버에 연결하지 못했어요. 인터넷 연결을 확인하거나 배포된 주소에서 시도해 주세요. |

| 테스트 | 결과 |

## 보너스 과제: 다크 모드

### 적용 내용

- 색을 변수로 정리하고, 다크 모드에서는 변수 값만 바꿔 화면 전체에 적용했습니다.
- 기기의 다크 모드 설정(`prefers-color-scheme`)을 따르고, 오른쪽 위 버튼으로 직접 바꿀 수 있습니다.
- 고른 화면은 브라우저에 저장해(`goseuran.theme`) 다시 열어도 유지합니다.
- 페이지가 그려지기 전에 저장된 화면을 먼저 적용해, 밝은 화면이 잠깐 보였다 바뀌는 깜빡임을 막았습니다.
- 화면이 바뀔 때 색이 부드럽게 전환되고, 기기의 "동작 줄이기" 설정을 켜면 전환 효과를 끕니다.

### 개선 효과를 확인하는 방법

| 확인 항목 | 기준 | 결과 |
|---|---|---|
| 본문 글자와 배경의 대비 | WCAG AA 기준 4.5:1 이상 | 계산값 약 14:1 |
| 보조 글자와 배경의 대비 | 4.5:1 이상 | 계산값 약 6.6:1 |
| 강조색(버튼, 분류 표시)과 카드 배경 | 4.5:1 이상 | 계산값 약 6.4:1 |
| 오류 문구와 카드 배경 | 4.5:1 이상 | 계산값 약 6.3:1 |
| 선택 유지 | 새로 고침 후에도 같은 화면 | 확인 |
| 휴대폰 폭에서 버튼 배치 | 메뉴와 겹치지 않음 | 확인 |

대비 값은 색상 코드로 계산한 값입니다. 앞으로 방문자 분석을 붙이면 다크 모드 사용 비율로 실제 사용을 확인할 수 있습니다.

## 개인정보와 데이터

- 기록은 지금 쓰는 브라우저에만 저장됩니다. 서버에는 저장하지 않습니다.
- 다른 기기나 다른 브라우저에서는 보이지 않고, 사이트 데이터를 지우거나 시크릿 창을 닫으면 사라집니다.
- `하루 정리하기`를 누르면 그날의 기록이 AI 서비스로 전송됩니다. 개인정보나 민감한 내용은 적지 않도록 안내합니다.
- 예시 기록은 시연을 위한 샘플이며, 직접 쓴 기록이 아닙니다. 화면에 "예시" 표시가 붙습니다.

## 알려진 한계

- 기록과 AI 결과가 서버에 저장되지 않습니다. AI 결과는 새로 고치면 사라집니다.
- 기록 시각은 저장한 순간의 기기 시각입니다. 지난 일을 나중에 적으면 실제 시각과 다릅니다.
- 서술어가 없는 기록(예: "저녁 국수")은 에세이에 적힌 모양 그대로 들어갑니다.
- 다크 모드 버튼을 한 번 누르면 그 뒤로는 기기 설정보다 고른 화면이 우선합니다.
- 호출 횟수 제한은 없고, 접근 코드와 API 키의 사용량 한도로 보호합니다.
- AI 출력은 실행할 때마다 조금씩 달라질 수 있습니다.
