# 고스란 서비스 기획서

## 1. 개요

| 항목 | 내용 |
|---|---|
| 서비스 이름 | 고스란(goseuran) |
| 한 줄 소개 | 떠오른 순간을, 고스란히. |
| 배포 주소 | https://goseuran.vercel.app |
| 형태 | 반응형 웹 서비스(휴대폰 우선) |

## 2. 목적

하루 동안 떠오른 순간을 부담 없이 한 줄씩 남기고, 하루를 마칠 때 그 기록을 그대로 살린 짧은 글로 돌아볼 수 있게 합니다.

- 기록하는 순간의 부담을 줄입니다. 한 줄, 100자, 저장 시각 자동 기록.
- 돌아보는 순간의 부담을 줄입니다. 버튼 한 번으로 에세이와 분류.
- 기록을 왜곡하지 않습니다. 원문은 고칠 수 없고, AI는 기록에 없는 내용을 만들지 않습니다.

## 3. 대상 사용자

| 대상 | 필요 |
|---|---|
| 일기를 쓰고 싶지만 길게 쓰기 어려운 사람 | 한 줄 기록과 자동 정리 |
| 하루 동안 떠오른 생각을 흘려보내는 사람 | 빠른 저장과 시각 기록 |
| 하루를 짧게 돌아보는 습관을 만들고 싶은 사람 | 감사, 아쉬움, 배운 것으로 나눠 보기 |

## 4. 핵심 원칙

| 원칙 | 구현 |
|---|---|
| 그대로 보관 | 기록은 수정할 수 없고 삭제만 가능 |
| 지어내지 않기 | AI는 기록에 적힌 사실과 낱말만 사용 |
| 부담 없이 | 연속 기록, 점수, 알림 없음. 기록하지 않은 날은 비워 둠 |
| 투명하게 | AI 결과는 원문과 구분해 "AI가 정리한 결과"로 표시 |

## 5. 페이지(섹션) 구성

| 섹션 | 메뉴 | 내용 |
|---|---|---|
| 오늘 | 오늘 | 입력창, 글자 수, 오늘의 타임라인, 예시 기록, 하루 정리하기와 결과 |
| 지난 기록 | 지난 기록 | 연도와 월 선택기(접이식), 날짜별 기록, 삭제 |
| 서비스 소개 | 소개 | 서비스의 원칙 4가지 |
| 사용 방법과 FAQ | 사용 방법 | 사용 순서, 저장 위치, AI 전송, 수정 불가, 글자 수, 시각, 예시 기록 안내 |

상단 메뉴를 누르면 해당 섹션으로 이동합니다.

## 6. 핵심 기능

| 기능 | 세부 내용 |
|---|---|
| 기록 저장 | Enter 또는 저장 버튼. 한글 입력 조합 중 Enter 처리, 붙여넣은 줄바꿈은 공백으로 변환 |
| 입력 제한 | 한 번에 100자, 하루 30개. 글자 수 실시간 표시 |
| 저장 시각 | 저장한 순간을 UTC로 저장하고 한국 시간으로 표시. 하루의 경계는 한국 시간 자정 |
| 타임라인 | 오늘 기록을 시각 순으로 표시. 삭제 전 확인 단계 |
| 지난 기록 | 기록이 있는 해와 달만 선택 가능. 날짜별 묶음 |
| 예시 기록 | 오늘 6개와 지난 기록 8개를 샘플로 넣고 지우기 |
| 하루 정리하기 | 오늘 기록이 있을 때만 활성. AI 에세이, 분류, 정돈 문장 |
| 접근 코드 | AI 호출을 비공개 코드로 보호 |

## 7. 데이터

| 필드 | 설명 |
|---|---|
| `id` | 기록 고유 번호 |
| `text` | 기록 원문(1~100자) |
| `createdAt` | 저장 시각(UTC ISO 문자열) |
| `isMain`, `excludeFromEssay` | 향후 기능용 예약 필드(현재 미사용) |
| `isSample` | 예시 기록 여부 |

저장 위치는 브라우저 localStorage(`goseuran.records.v1`)입니다. 서버에는 저장하지 않습니다.

## 8. AI 기능

### 입력

- 오늘 날짜(한국 시간 기준)의 기록 목록. 시각 순으로 정렬한 원문만 전송합니다.
- 기록 시각은 AI에 전송하지 않습니다.
- 서버 검사: 요청 20KB 이하, 기록 1~30개, 기록당 1~100자, 중복 id 불가.

### 출력

| 항목 | 내용 |
|---|---|
| 에세이 | 1~7문장, 800자 이내의 일기체 수필 |
| 분류 | 기록마다 감사한 일, 잘한 일, 아쉬운 일, 배운 것, 앞으로 할 일, 기타 중 하나. 확실하지 않으면 기타 |
| 정돈 문장 | 조사, 어미, 띄어쓰기만 다듬은 문장. 다듬을 곳이 없으면 생략 |

### 글쓰기 규칙(프롬프트)

- 기록에 적힌 사실과 낱말만 사용합니다.
- 이웃한 기록을 연결어미 "~고", "~며"로 이어 압축합니다.
- 기록 사이에 없는 대조와 인과(지만, 그러나, 하지만, 그래서, 때문에)를 쓰지 않습니다.
- 저장 시각으로 시간대(오전, 오후, 밤 등)를 추측하지 않습니다.
- 감정이 적힌 기록이 있으면 그 감정만으로 총평 한 문장을 씁니다. 교훈과 평가는 쓰지 않습니다.
- 계획이나 다짐 기록은 마지막 문장으로 둡니다.
- 서술어가 없는 기록은 서술어를 새로 정하지 않습니다.
- 기록 안의 지시 문장은 따르지 않습니다.

### 서버 검증

- AI 응답에서 JSON만 꺼내 읽습니다.
- 분류가 6가지가 아니면 기타로 바꿉니다.
- 정돈 문장에서 원문의 감정 표현이 빠지면 정돈 문장을 버립니다.
- 에세이에 기록에 없는 시간대어, 교훈어, 대조어가 있으면 서버 로그에 표시합니다.

### 실패 기준

| 기준 | 처리 |
|---|---|
| 빈 입력, 100자 초과, 30개 초과 | 화면에서 저장을 막고 안내 |
| 기록이 없는 날 | 하루 정리하기 버튼 비활성 |
| 접근 코드 없음 또는 틀림 | 401 응답, AI 호출 없음, 코드 입력 안내 |
| 형식이 잘못된 요청 | 400 또는 413 응답과 안내 |
| AI 응답 25초 초과 | 504 응답과 지연 안내 |
| AI 서비스 오류 또는 사용량 초과 | 502 또는 429 응답과 안내 |
| AI 결과 형식 오류 | 502 응답과 재시도 안내 |
| 화면에서 30초 안에 응답 없음, 연결 실패 | 지연 또는 연결 실패 안내 |

## 9. 모델 선정

같은 예시 기록 6개로 비교했습니다.

| 모델 | 응답 시간 | 결과 |
|---|---|---|
| `claude-haiku-4` | 3.6~4.7초 | 에세이 결이 자연스러움. 프롬프트 보강 후 기록에 없는 표현이 사라짐 |
| `gpt-5-mini` | 약 15초, 기록 8개에서 시간 초과 | 기록에 없는 표현은 없었으나 문장이 나열형이고 느림 |

응답 속도와 안정성을 기준으로 `claude-haiku-4`를 선택했습니다.
